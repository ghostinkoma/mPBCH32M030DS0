# 設計検討書 — mPBCH32M030DS0 (Rev 0.3)

> **Rev 0.3**: MOSFET 群を子基板 (A: TPN1R603PL / B: TKR74F04PB 24V / C: MTN2306AN3 / D: MOSFET なし) に分離し,
> 主基板・子基板とも 2 層の基板レイアウトを作成しました。コネクタはすべてピンヘッダ、コンデンサは 1005/1608 が基本です。
> 構成・ピン配置・レイアウト・コンデンサ品番は [stacking.md](stacking.md) を参照してください。

> Rev 0.2 の内蔵機能活用 (USB-PD 給電, CMP3 BEMF, QII1, ISOURCE 診断) は [advanced_features.md](advanced_features.md) にまとめています。

CH32M030C8U7 (QFN48) + TPN1R603PL によるユニバーサル・モータードライバの部品選定と回路設計の根拠。
数値の出典は WCH **CH32M030DS0 V1.2 (データシート)**、**CH32M030RM V1.2 (リファレンスマニュアル)**、
WCH 公式 EVT (`openwch/ch32m030`) と東芝 TPN1R603PL データシートです。

## 2. 回路設計の詳細

### 2.1 PWM とハーフブリッジの割当

| モード | HB0 / HB1 | HB2 / HB3 | 電流 IB (JP5) |
|---|---|---|---|
| 3 相 | TIM1 CH1/CH2 (+HB2 = TIM1 CH3) | HB3 未使用 | 1-2 (HB1 = V 相) |
| DC 1ch | TIM1 CH1/CH1N, CH2/CH2N | — | どちらでも |
| DC 2ch / ステッピング | TIM1 CH1/CH2 (A 側) | **TIM2 リマップ2**: PB13/PB12 = CH1/CH1N, PB15/PB14 = CH2/CH2N (B 側) | 2-3 (HB2) |

- TIM1 はデフォルト配置で HB0〜HB2 に接続。**TIM1 リマップ1** でも CH1〜CH3 は同じピンのまま、BKIN が PA13 (nFAULT) に移る。
- TIM2 は BKIN を持たない → B 側の過電流は CMP3 割込みで TIM2 出力を止める (µs オーダ)。A 側は TIM1 ブレーキでハード遮断。
- ドライバ内蔵のシュートスルー防止があるが、FW でも必ずデッドタイムを設定する。

### 2.2 ゲート駆動の見積り

- 平均ゲート電流: 41nC × 20kHz × 8 石 ≈ 6.6mA (VDD8 から)
- スイッチング時間: ターンオン ≈ QSW / 55mA ≈ 0.2µs, ターンオフ ≈ 11nC / 120mA ≈ 0.09µs (+遅延 ≈ 0.25µs)
- **デッドタイム初期値 0.5µs**、PWM **16〜20kHz** を推奨 (実測で詰める)
- 損失 (12V, 10A, 20kHz): スイッチング ≈ 0.5×12×10×0.29µs×20k ≈ 0.35W + 導通 ≤0.24W → 1 石 0.6W 程度

### 2.3 電流・電圧の計測 (内蔵 ADC)

| 信号 | 経路 | ADC | 分解能 / 範囲 |
|---|---|---|---|
| IA (HB0 レッグ) | 10mΩ → R16/R17/C19 → ISP1/ISN1 → **OPA3** | IN9 (内部) | G16: 10mV/A×16, ±10A |
| IB (HB1 or HB2) | 10mΩ → JP5 → R18/R19/C20 → ISP2/ISN2 → **OPA4** | IN10 (内部) | 同上 |
| IBUS (全電流) | バス 10mΩ → R13/C17 → PB3 (直接) | IN1 | 10mV/A, ≈81mA/LSB |
| VBUS | 110k/10k → PB4 | IN17 | ≈9.7mV/LSB, 〜28.8V (入力上限 VDD33−0.9V) |
| 温度 | NTC 10k ← PA4 ISOURCE1 | IN5 | |
| 相電圧 U/V/W | 20k/3k → JP2〜JP4 → PA5/PA7/PA6 | IN6/IN2/(W は ADC 無し) | センサレスは CMP3 + 内部仮想中性点で検出 (docs/advanced_features.md) |
| USB VBUS | 120k/10k → PA2 | IN15 | PD 契約電圧の確認・抜去検出 |
| 過電流閾値 | 12k/1k → PB2 | IN0 | 254mV = 25.4A (読み戻し可) |

- 3 相: Iu = IA, Iv = IB, Iw = −(Iu+Iv)。IBUS は電力計算・保護用。
- ステッピング / DC 2ch: A 相 = IA, B 相 = IB (JP5=2-3)。中心揃え PWM で下側 ON 期間に標本化する。
- ADC は注入グループを TIM1 (TRGO) で起動し、PWM 中央でサンプリングする。

### 2.4 電源と LDO の負荷配分

| 電源 | 負荷 | 概算 |
|---|---|---|
| VDD8 (上限 35mA) | ゲート電荷 6.6mA + ゲート確認 LED (H/L 各 ≈0.36mA×4) + VDD33 全量 | ≈ 25mA |
| VDD33 (上限 20mA) | MCU 12mA (72MHz, 全周辺) + 3V3 LED 0.9mA + 状態 LED + プルアップ | ≈ 15mA |
| VHV (上限 60mA) | 上記全体 | LDO 損失 ≈0.25W (VHV 15V 時) |

- 3.3V 系の外部供給は J4/J5/J6 の 3V3 ピン経由で**数 mA まで**。それ以上は外部で用意する。
- 5V (78L05) はホールセンサと +5V LED、J6 の 5V ピン用 (合計 ≤ 60mA 目安)。

### 2.5 保護

| 事象 | 対策 |
|---|---|
| 逆接続 / 逆流 | U4+Q9 / U5+Q10 の理想ダイオードが遮断 (J1 と USB-PD の相互逆流も阻止) |
| 過電流 | CMP3 (IBUS vs 25.4A) → TIM1 BKIN、CMP2 (IA) → TIM1 BKIN、TIM2 は CMP3 割込みで停止。F1 15A |
| 過電圧 | PB4 OVP: VBUS 18.0V で MCU リセット (全ゲート OFF)。TVS SMBJ16A |
| 過熱 | NTC (FW) + チップ OTP |
| 外部非常停止 | nFAULT (J6-7, PA13 = TIM1_BKIN_1) |
| 起動時 / ブートローダ中 | HO は Low 出力、LO は内部プルダウン (解除不可) + 外部 20k → 全 FET OFF |

### 2.6 ゲート確認 LED

各ハーフブリッジに 2 個 (H: GHx–SWx 間 赤, L: GLx–SRCx 間 緑)。22kΩ 直列で約 0.36mA (VDD8=10V)。
PWM デューティに比例した明るさで点灯し、上下同時点灯が無いこと (= デッドタイムが効いていること) を目視確認できる。
ハイ側 LED の電流はブートストラップ容量から供給される (ダイオード平均上限 7mA に対し十分小さい)。
量産時は R35/R36 などを未実装にして無効化できる。

## 4. 残る確認事項 (試作前)

1. TSON Advance の東芝推奨ランドと PowerPAK 1212-8 ランドの寸法照合 (特にドレインパッド形状)
2. I2C リマップ2 (PA14/PA15) 使用時に OPA3/OPA4 の ADC 内部接続と干渉しないこと
   (RM: PA14/PA15 を外部 ADC 入力にする時のみ QDET_EN=1 が必要 → 通常は干渉しない想定)
3. USB のみ給電 (VHV ≈ 4.5V) 時の USB 動作確認 (DS: VHV<5V で PA0〜PA3 の出力振幅が低下。D+/D- は PB0/PB1 なので影響なし想定)
4. TIM2 リマップ2 で HB2/HB3 を駆動する際、TIM1 CH3/CH3N の出力を無効化すること (同一ピンの競合)
5. RST ピン (PC0) はオプションバイトで有効化が必要 (WCH-LinkUtility)
6. Rev 0.2 で追加した内蔵機能 (CMP3 RMID, LM74700, ISOURCE 診断, PD) の確認事項は [advanced_features.md §6](advanced_features.md#6-要実機確認) を参照
7. (Rev 0.3) 子基板 B の TO-220SM(W) ランド: KiCad TO-263-2 で暫定 → 東芝提供ランドへ差し替え。Qg と VDD8 35mA 予算の確認
8. (Rev 0.3) NANO2 ヒューズ (F1) のランド寸法を Littelfuse 推奨値と照合 (`hardware/lib/mPB.pretty`)
9. (Rev 0.3) 低背ピンソケット (嵌合高さ ≈5mm) の品番選定と M2 スペーサ長の決定。BOTTOM 面部品の高さ ≤2mm を維持
10. (Rev 0.3) 製造: 2 層 1.6mm, 最小 0.127mm 線幅/間隙, 0.2mm 穴 (QFN サーマルビア) に対応する基板メーカーを選ぶ
