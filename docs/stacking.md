# MCU モジュール + パワー段子基板 (Rev 0.4) — 構成と基板レイアウト

Rev 0.4 では、MCU 周りを **DIP-42 のモジュール** (ブレッドボードに挿せる幅) にまとめました。
MOSFET 群 (パワー段) は子基板 A / B / C に分け、モジュールを子基板のピンソケットへ上から挿して使います。

```
                ┌──────────── MCU モジュール TOP 面 (上向き) ────────────┐
                │ USB-C / RESET・USER / JP2-4・JP8 / LED (電源・状態・ゲート ×8) │
                └──────────── MCU モジュール BOTTOM 面 ──────────────────┘
                   J1 (1x21)  ↓   小型 CR (高さ ≤1.65mm)   ↓  J2 (1x21)      ← ピンヘッダ (標準 2.54mm)
                   J1 (1x21)  ↑  バルク容量・電源部品 (≤7mm) ↑  J2 (1x21)     ← ピンソケット (高さ 8.5mm)
                ┌──────────── 子基板 TOP 面 ────────────────────────────┐
                │  ソケット ×2, 電源入力 J3 (2x6), モータ出力 J4 (2x8), 電源部       │
                └──────────── 子基板 BOTTOM 面 (ヒートシンク側) ───────────────┘
                     MOSFET ×8 / シャント / ゲート抵抗 / 電流チャネル選択 JP5・JP7
```

- **嵌合は左右対称**です。モジュールの左右端にある 1x21 ピン 2 列 (列間 17.78mm) を、子基板の同じ位置の 1x21 ソケット 2 列で受けます。
  Rev 0.3 は基板間コネクタが片側に寄っていたため、モジュールが傾いて接触不良の原因になりました。Rev 0.4 では 42 本のピンが
  基板の全長にわたって均等に荷重を受けます。
- モジュール J1/J2 と子基板 J1/J2 は**同じピン番号・同じネット名**です (鏡像になりません)。回路図生成スクリプトの同じピン表
  (`EDGE_L` / `EDGE_R`) から両方を作っています。並び順は CH32M030 (QFN48) の各辺のピン順に合わせ、
  モジュール上の引き出し配線が交差しにくいようにしています (上辺 → J1/J2 上部、ゲート → J2 中央、アナログ → J1 下部)。ピン配置は [README](../README.md#モジュールのピン配置-上面から見て-usb-c-が上-子基板のソケット-j1j2-も同じ) を参照してください。
- 基板の間隔は約 11mm です (ソケット 8.5mm + ピンヘッダのプラスチック 2.5mm)。子基板 TOP 面のモジュール真下には
  **高さ 7mm 以下**の部品 (バルク容量 EEE-FK 6.2mm など) を置いています。
- **LED はすべてモジュール上面**です。子基板の BOTTOM 面はヒートシンクで覆われ、TOP 面はモジュールの下に隠れるためです。
  ゲート確認 LED (D10〜D17) は HOx–SWx / LOx–GND の間に 22kΩ 経由で接続しています。ゲート信号はモジュール上にあるので、
  子基板を付けずに外付けのパワー段で使う場合も点灯します。
- 電圧系に依存する部品 (TVS D1、VBUS 分圧 R11/R12 = OVP、バルク容量、相電圧分圧) は子基板側にあります。
  モジュールはどの子基板でも共通です。

## ブレッドボードで使う

- モジュールは 22.86mm 幅 (**9 マス**) × 53.34mm (21 マス)、端子列は 0.7in 間隔 (Raspberry Pi Pico と同じ) です。
  一般的な 82 × 52mm (30 列) のブレッドボードに、中央の溝をまたいで左右対称に挿せます (端子は c 列と h 列)。
  両側に 1 列ずつ (a / j) 配線用の穴が残ります (b / i 列は基板の縁の真下)。
- ピンヘッダは**表・裏どちらからでも**はんだ付けできます。
  - 下向き (BOTTOM 側へ出す): ブレッドボードや子基板のソケットに挿す通常の使い方です。
  - 上向き (TOP 側へ出す): モジュールを平置きし、ジャンパワイヤ (メス) でつなぐ使い方です。
  - 信号名は BOTTOM 面のシルクに、各ピンの内側に印字しています (TOP 面は部品で埋まっているため)。
- USB-C だけで MCU・書き込み・USB 通信が動作します。モータを回すには VBUS ピンに 8V 以上を入れ、
  HO/LO/SW に外付けのパワー段をつなぎます。VBUS_SNS には外付けの分圧 (110k/10k など) が必要です。

- バルク容量は Rev 0.3 の 470µF/330µF (背が高い) から、モジュール下に収まる**高さ 6.2mm の低背品**に変えました。
  容量が減った分、モータ電源の配線は短くし、必要なら J3 の近くに外付けの電解コンデンサを追加してください。
- **B** の注意点 (24V 系):
  - CH32M030 の VS 絶対最大は 30V、VHV の動作範囲は 5〜28V です (データシート表 3-1)。
    24V 系は安定化電源専用とし、回生やサージで 28V を超えないようにしてください。
    モジュールの VHV は R10 47Ω + D4 27V で保護しています。
  - TKR74F04PB はゲート電荷が大きいので、VDD8 LDO (35mA) の予算を確認してください。
    `8 × Qg × fPWM + MCU の消費 ≤ 35mA` が条件です (例: Qg 150nC なら fPWM ≤ 20kHz)。
  - TO-220SM(W) のランドは、KiCad 標準の TO-263-2 で暫定的に作っています。
    東芝提供のランドパターンに差し替えてから発注してください。
- **C** は SOT-23 の小型品です。小型 DC モータやステッピング (≤1.5A/相) 向けです。

## 基板レイアウト (2 層)

生成手順 (`hardware/gen_pcb.py`, KiCad 8.0 の pcbnew):

1. 部品を配置します (courtyard の重なり・反対面の THT 穴との干渉を検査)。
2. Freerouting 1.9 で自動配線します。
3. 大電流ネットの周囲をベタで太らせます。
4. GND ベタ (両面) とスティッチングビアを入れます。
5. 自動配線で残った接続を格子 A* で補修します。DRC が増えない経路だけを採用します。
6. DRC を実行します。

図は `docs/pcb/*_top.svg` / `*_bottom.svg` です (BOTTOM 面は裏から見た鏡像)。

### MCU モジュール (22.86 × 53.34mm)

| 面 | 上から順に |
|---|---|
| **TOP** | USB-C J8 → ESD U3・RESET SW1 → CH32M030 (QFN48, 中央) → ゲート LED ×8 → センシング選択 JP2〜JP4・JP8、VHV 保護 D4〜D6・F2 → USER/BOOT SW2 → 電源 LED ×3・状態 LED |
| **BOTTOM** | USB 周りの CR → MCU のデカップリング (QFN の裏面パッドのサーマルビアを避けて上側) → 水晶 Y1・C131/C132 (XI/XO 直下) → ブートストラップ C21〜C24 (ゲートピン側)・電流アンプ入力 RC → ホール入力 RC・I/O 直列抵抗 |

- QFN (0.35mm ピッチ) の引き出しのため、線幅・間隙は 0.127mm です (JLCPCB の 2 層標準の最小値)。
- BOTTOM 面の部品はすべて 1.65mm 以下 (最も高いのは 1206 の 10µF。3D モデルで確認) で、ピンヘッダのプラスチック (2.5mm) より低いので、ブレッドボードにもソケットにも当たりません。

### 子基板 A / C (22.86 × 74.9mm)

大電流の銅箔 (VBUS・各相 SW・SRC・ISH・VIN・GND) は**配線より先に固定のベタとして置き**, 残りの信号だけを自動配線しています
(`gen_pcb.py build_daughter_a`)。上から順に:

- 上端 (モジュールの USB 側): USB-PD 経路 F3 → Q10 (理想ダイオード U5) → VBUS, 78L05 U2, バルク容量 C7 (TOP)。
- レッグ 3 → 0 (J2 の HO/SW/LO の並びと同じ高さ)。BOTTOM 面にハイサイド/ローサイド MOSFET・シャント・レッグの C,
  TOP 面に各相の SW 帯 (J4 へ下る縦の帯) と VBUS 帯。ゲート抵抗 (A は 0805) は J2 の HO/SW/LO の間に置いています。
- レッグ 0 の下: バスシャント R70・相電圧分圧・VBUS 分圧 (BOTTOM), NTC TH1 (TOP), 電源入力 Q9 (理想ダイオード U4)・F1。
- 下端: **J3 (電源, 左) と J4 (モータ出力, 右) は縦向き**です。J3 は上 3 段が GND・下 3 段が VIN、J4 は**上から OUT3 → OUT0** の順です。
- 電流チャネル選択 JP5 / JP7 は TOP 面の J1 の横です (はんだジャンパ, 既定は 1-2 ブリッジ)。
- ヒートシンクは BOTTOM 面の MOSFET に絶縁シートを挟んで当ててください (ドレインは VBUS / 各相出力です)。
- USB 側の TVS (旧 D9) は置き場所が取れず外しました。USB_VBUS のサージは Q10 のボディダイオードを通って VBUS のバルク容量と
  TVS D1 で吸収され、LM74700 (U5) の耐圧は 65V です。

#### 電源ベタのはんだ盛り (1oz のまま電流を増やす)

電源ベタの上はレジストを開けてあり (ベタの形を 0.25mm 内側に縮めた開口), はんだを盛って厚みを稼げます。
銅の縁と隣のネットの間はレジストが残るので, 盛ってもブリッジしにくくなっています。

- はんだ 0.3mm (Sn63Pb37) で, 1oz の銅にほぼ 1oz を足したのと同じ効果です (はんだの抵抗率は銅の約 8.5 倍)。
  電流容量チェック (`hardware/tools/power_check`, 1mm 平均の電流密度, IPC-2221 外層 ΔT 20°C) の結果:

  | | 1oz のまま | はんだ 0.3mm |
  |---|---|---|
  | A (設計 5A/相, USB 3A) | 最小 4.1A (SW2) / USB 経路 5.1A | **最小 5.9A** (SW) / USB 経路 5.1A |
  | C (設計 3A/相, USB 3A) | 最小 4.1A / USB 帰路 GND 3.0A | 最小 5.9A / USB 帰路 GND 3.0A |

- **表面処理のハンダレベラー (HASL) だけでは厚みはほとんど増えません** (数〜数十 µm)。効果を出すには, 基板が届いてから
  開口部にはんだを手で盛ってください (はんだごて + 太めの糸はんだ, または開口部にペーストを塗ってリフロー)。
  A の最小経路 (SW) の許容電流: 盛り無し 4.1A / HASL 相当 0.02mm 4.2A / 0.1mm 4.7A / 0.2mm 5.3A / 0.3mm 5.9A。
- BOTTOM 面 (ヒートシンク側) の盛りは 0.3〜0.5mm 以下にしてください (MOSFET の高さ + 放熱シートより低く)。
- 盛ったはんだは**低温はんだ (Sn-Bi など) 不可**です (融点・強度とも不足)。手直しで部品を外すときは, 盛ったはんだも溶かす必要があります。

### 子基板 B (43.18 × 66.94mm)

- モジュールは基板の左右中央です (ソケット列 x = 12.70 / 30.48mm)。
- BOTTOM 面: TO-263 ×8 をソケット端子列の間を避けて **3 列 × 3 段**に並べ、中央下段にバスシャント・JP5/JP7・相電圧分圧・NTC を置きました。
- TOP 面: モジュール真下に電源部、モジュールの左右 (外側) に各レッグのシャント・ゲート抵抗・コンデンサ。

## MCU モジュールの配線

QFN48 (0.35mm ピッチ) と 42 本の端子列の間は 2 層では混み合うため、水晶 Y1 と負荷容量 C131/C132 を
QFN 下辺の XI/XO (8/9 番ピン) 直下の裏面へ置き、表の下辺ピン 1〜7 の引き出しを空けて自動配線を通しきっています。
線幅・間隙 0.127mm / ビア 0.6mm (穴 0.3mm) で、JLCPCB の 2 層標準の範囲です。

- 以前の 20.32mm 幅 (8 マス) 版は 0.127mm では未接続が 20 か所前後残り (0.10mm なら通るが 2 層標準外)、廃止しました。
- 手直し用のベタなし版: `hardware/nopour/`
- ベタなし版は配線とビアを残し、GND ベタ・大電流の太らせたベタ・スティッチングビアだけを外したものです。
  手直しするときに使い、終わったら GND ベタ (両面) を引き直し、ステッチングビアを打ってください。
