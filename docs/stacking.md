# MCU モジュール + パワー段子基板 (Rev 0.4) — 構成と基板レイアウト

Rev 0.4 では、MCU 周りを **DIP-42 のモジュール** (ブレッドボードに挿せる幅) にまとめました。
MOSFET 群 (パワー段) は子基板 A / B / C に分け、モジュールを子基板のピンソケットへ上から挿して使います。

```
                ┌──────────── MCU モジュール TOP 面 (上向き) ────────────┐
                │ USB-C / RESET・USER / JP2-4・JP8 / LED (電源・状態・ゲート ×8) │
                └──────────── MCU モジュール BOTTOM 面 ──────────────────┘
                   J1 (1x21)  ↓   小型 CR (高さ ≤1.3mm)   ↓  J2 (1x21)      ← ピンヘッダ (標準 2.54mm)
                   J1 (1x21)  ↑  バルク容量・電源部品 (≤7mm) ↑  J2 (1x21)     ← ピンソケット (高さ 8.5mm)
                ┌──────────── 子基板 TOP 面 ────────────────────────────┐
                │  ソケット ×2, 電源入力 J3 (2x6), モータ出力 J4 (2x8), 電源部       │
                └──────────── 子基板 BOTTOM 面 (ヒートシンク側) ───────────────┘
                     MOSFET ×8 / シャント / ゲート抵抗 / 電流チャネル選択 JP5・JP7
```

- **嵌合は左右対称**です。モジュールの左右端にある 1x21 ピン 2 列 (列間 15.24mm) を、子基板の同じ位置の 1x21 ソケット 2 列で受けます。
  Rev 0.3 は基板間コネクタが片側に寄っていたため、モジュールが傾いて接触不良の原因になりました。Rev 0.4 では 42 本のピンが
  基板の全長にわたって均等に荷重を受けます。
- モジュール J1/J2 と子基板 J1/J2 は**同じピン番号・同じネット名**です (鏡像になりません)。回路図生成スクリプトの同じピン表
  (`EDGE_L` / `EDGE_R`) から両方を作っています。並び順は CH32M030 (QFN48) の各辺のピン順に合わせ、
  モジュール上の引き出し配線が交差しにくいようにしています (上辺 → J1/J2 上部、ゲート → J2 中央、アナログ → J1 下部)。ピン配置は [README](../README.md#モジュールのピン配置-上面から見て-usb-c-が上-子基板のソケット-j1j2-も同じ) を参照してください。
- 基板の間隔は約 11mm です (ソケット 8.5mm + ピンヘッダのプラスチック 2.5mm)。子基板 TOP 面のモジュール真下には
  **高さ 7mm 以下**の部品 (バルク容量 EEE-FK 6.2mm など) を置いています。
- **LED はすべてモジュール上面**です。子基板の BOTTOM 面はヒートシンクで覆われ、TOP 面はモジュールの下に隠れるためです。
  ゲート確認 LED (D10〜D17) は HOx–SWx / LOx–GND の間に 22kΩ 経由で接続しています。ゲート信号はモジュール上にあるので、
  子基板を付けずに外付けのパワー段で使う場合も点灯します。
- 電圧系に依存する部品 (TVS D1、VBUS 分圧 R11/R12 = OVP、バルク容量、相電圧分圧) は子基板側にあります。
  モジュールはどの子基板でも共通です。

## ブレッドボードで使う

- モジュールは 20.32mm 幅 (**8 マス**) × 53.34mm (21 マス) です。一般的な 82 × 52mm (30 列) のブレッドボードに、
  中央の溝をまたいで挿せます。両側に 1 列ずつ配線用の穴が残ります。
- ピンヘッダは**表・裏どちらからでも**はんだ付けできます。
  - 下向き (BOTTOM 側へ出す): ブレッドボードや子基板のソケットに挿す通常の使い方です。
  - 上向き (TOP 側へ出す): モジュールを平置きし、ジャンパワイヤ (メス) でつなぐ使い方です。
  - 信号名は BOTTOM 面のシルクに、各ピンの内側に印字しています (TOP 面は部品で埋まっているため)。
- USB-C だけで MCU・書き込み・USB 通信が動作します。モータを回すには VBUS ピンに 8V 以上を入れ、
  HO/LO/SW に外付けのパワー段をつなぎます。VBUS_SNS には外付けの分圧 (110k/10k など) が必要です。

| 連続電流の目安 | 約 10A (ピンヘッダ律速) | 約 10A (出力ランドへ直付けで 20A 級) | 約 3A |
| 基板寸法 | **20.32 × 71.94mm** | **40.64 × 66.94mm** | **20.32 × 71.94mm** |
| ゲート抵抗 / G-S | 47Ω / 20kΩ | 22Ω / 10kΩ | 47Ω / 20kΩ |
| シャント (各レッグ + バス) | 10mΩ 2512 2W | 10mΩ 2512 3W | 10mΩ 1206 0.5W |
| バルク容量 | 100µF/25V ×2 (Panasonic EEE-FK1E101P, 8 × 6.2mm) | 47µF/35V ×3 (EEE-FK1V470P, 6.3 × 6.1mm) | 100µF/25V ×1 |
| TVS / OVP 分圧 | SMBJ16A / 110k:10k (18V) | SMBJ24A / 180k:10k (28.5V) | SMBJ16A / 110k:10k |
| 相電圧分圧 (BEMF) | 20k / 3k | 47k / 3.3k | 20k / 3k |
| ファームウェア | `make POWER_STAGE=A` (既定) | `make POWER_STAGE=B` | `make POWER_STAGE=C` |

- バルク容量は Rev 0.3 の 470µF/330µF (背が高い) から、モジュール下に収まる**高さ 6.2mm の低背品**に変えました。
  容量が減った分、モータ電源の配線は短くし、必要なら J3 の近くに外付けの電解コンデンサを追加してください。
- **B** の注意点 (24V 系):
  - CH32M030 の VS 絶対最大は 30V、VHV の動作範囲は 5〜28V です (データシート表 3-1)。
    24V 系は安定化電源専用とし、回生やサージで 28V を超えないようにしてください。
    モジュールの VHV は R10 47Ω + D4 27V で保護しています。
  - TKR74F04PB はゲート電荷が大きいので、VDD8 LDO (35mA) の予算を確認してください。
    `8 × Qg × fPWM + MCU の消費 ≤ 35mA` が条件です (例: Qg 150nC なら fPWM ≤ 20kHz)。
  - TO-220SM(W) のランドは、KiCad 標準の TO-263-2 で暫定的に作っています。
    東芝提供のランドパターンに差し替えてから発注してください。
- **C** は SOT-23 の小型品です。小型 DC モータやステッピング (≤1.5A/相) 向けです。

## 基板レイアウト (2 層)

生成手順 (`hardware/gen_pcb.py`, KiCad 8.0 の pcbnew):

1. 部品を配置します (courtyard の重なり・反対面の THT 穴との干渉を検査)。
2. Freerouting 1.9 で自動配線します。
3. 大電流ネットの周囲をベタで太らせます。
4. GND ベタ (両面) とスティッチングビアを入れます。
5. 自動配線で残った接続を格子 A* で補修します。DRC が増えない経路だけを採用します。
6. DRC を実行します。

図は `docs/pcb/*_top.svg` / `*_bottom.svg` です (BOTTOM 面は裏から見た鏡像)。

### MCU モジュール (20.32 × 53.34mm)

| 面 | 上から順に |
|---|---|
| **TOP** | USB-C J8 → ESD U3・RESET SW1 → CH32M030 (QFN48, 中央) → 水晶 Y1・ゲート LED ×8 → センシング選択 JP2〜JP4・JP8、VHV 保護 D4〜D6・F2 → USER/BOOT SW2 → 電源 LED ×3・状態 LED |
| **BOTTOM** | USB 周りの CR → MCU のデカップリング (QFN の裏面パッドのサーマルビアを避けて上側) → ブートストラップ C21〜C24 (ゲートピン側)・電流アンプ入力 RC → ホール入力 RC・I/O 直列抵抗 |

- QFN (0.35mm ピッチ) の引き出しのため、線幅・間隙は 0.127mm です (JLCPCB 等の標準 2 層で製造可能)。
- BOTTOM 面の部品はすべて 1.3mm 以下で、ピンヘッダのプラスチック (2.5mm) より低いので、ブレッドボードにもソケットにも当たりません。

### 子基板 A / C (20.32 × 71.94mm)

- TOP 面: モジュール真下にバルク容量 → 電源入力のヒューズ F1・TVS D1・理想ダイオード Q9/U4 → USB-PD 経路 F3/Q10/U5 → 78L05 → VBUS 分圧。
  下端に J3 (電源) と J4 (モータ出力)。
- BOTTOM 面 (ヒートシンク側): レッグ 0〜3 を上から順に並べました。各レッグはハイサイド/ローサイド MOSFET の横並び →
  シャントとレッグのコンデンサ → ゲート抵抗・プルダウン・ブートストラップ用 C。NTC TH1 はレッグ 1 の横 (MOSFET の間) です。
  最後にバスシャント R70、電流チャネル選択 JP5 / JP7、相電圧分圧。
- ヒートシンクは BOTTOM 面の MOSFET に絶縁シートを挟んで当ててください (ドレインは VBUS / 各相出力です)。

### 子基板 B (40.64 × 66.94mm)

- モジュールは基板の左右中央です (ソケット列 x = 12.70 / 27.94mm)。
- BOTTOM 面: TO-263 ×8 をソケット端子列の間を避けて **3 列 × 3 段**に並べ、中央下段にバスシャント・JP5/JP7・相電圧分圧・NTC を置きました。
- TOP 面: モジュール真下に電源部、モジュールの左右 (外側) に各レッグのシャント・ゲート抵抗・コンデンサ。
