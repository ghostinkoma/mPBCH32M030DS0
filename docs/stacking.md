# 主基板 + パワー段子基板 (Rev 0.3) — 構成と基板レイアウト

Rev 0.3 では MOSFET 群 (パワー段) を子基板に分けました。主基板 (MCU・USB・電源・I/O) は共通のまま、
用途に合わせて子基板 A〜D を差し替えます。

```
          ┌──────────────── 主基板 TOP 面 (上向き) ──────────────────┐
          │ (上向きの TOP 面に) RESET / USER・BOOT / USB-C / JP2-4・JP8 / GPIO  │
          └──────────────── 主基板 BOTTOM 面 ────────────────────────┘
             J9 (2x5) / J10 (2x11) ピンヘッダ ↓   MCU 周辺の小型 CR (高さ ≤1.3mm)
                          ↕  約 5mm  (M2 スペーサ + 低背ピンソケット)
             J1 (2x5) / J3 (2x11) 低背ピンソケット ↑
          ┌──────────────── 子基板 BOTTOM 面 ─────────────────────────┐
          │ (下向きの TOP 面に) MOSFET / シャント / ゲート LED / JP5・JP7 / 出力 │
          └──────────────── 子基板 TOP 面 (下向き = 外側) ──────────────┘
```

- **裏面同士を向かい合わせ**て重ねます。操作する部品 (主基板の RESET・USER/BOOT・USB-C、子基板の電流チャネル選択
  JP5/JP7) はどちらも外側 (各基板の TOP 面) に置いています。
- 基板の間は約 5mm です。BOTTOM 面に置く部品は **高さ 2mm 以下**としました。
  - 主基板: MCU 周辺の小型 CR (1005/1608/2012) を置いています。デカップリング、ブートストラップ、電流アンプ入力 RC、
    VBUS 分圧、I/O 直列抵抗、LM74700 の VCAP です。QFN (0.35mm ピッチ) の引き出し配線のため TOP 面を空けました。
  - 子基板: ソケットだけです。
  - 両面実装になるので製造費は上がりますが、基板の小型化を優先しました。
- 取付穴 M2 (H1〜H3) は両基板で同じ位置にあります (子基板 A/C/D)。子基板 B は上方へ張り出すため、位置が合うのは
  H1/H3 の 2 か所です。
- コネクタは USB-C 以外すべて 2.54mm ピンヘッダ (ソケット) です。

## 子基板のバリエーション

| | **A** (標準) | **B** (24V 系) | **C** (廉価版) | **D** (MOSFET なし) |
|---|---|---|---|---|
| MOSFET | TPN1R603PL ×8 (30V 1.6mΩ, TSON Advance) | **TKR74F04PB ×8** (40V 0.74mΩ, TO-220SM(W)) | **MTN2306AN3 ×8** (30V 5.5A 25mΩ, SOT-23) | なし |
| モータ電源 VBUS | 8〜16V (公称 12V) | 12〜24V (上限 26V, 安定化電源) | 8〜16V | 外付け段による |
| 連続電流の目安 | 約 10A (ピンヘッダ律速) | 約 10A (出力ランドへ直付けで 20A 級) | 約 3A | — |
| 基板寸法 | 60 × 42mm | 66 × 66mm | 60 × 42mm | 60 × 42mm |
| ゲート抵抗 / G-S | 47Ω / 20kΩ | 22Ω / 10kΩ | 47Ω / 20kΩ | 外付け側で |
| シャント (各レッグ + バス) | 10mΩ 2512 2W | 10mΩ 2512 3W | 10mΩ 1206 0.5W | 外付け側で (10mΩ 推奨) |
| バルク容量 | 470µF/25V ×2 | 330µF/35V ×2 | 220µF/25V | 220µF (任意, DNP) |
| 相電圧分圧 (BEMF) | 20k / 3k | 47k / 3.3k | 20k / 3k | 外付け側で ≤2.5V に |
| 主基板の変更 | なし | **D1 = SMBJ24A, R11 = 180kΩ**、FW は `make POWER_STAGE=B` | なし | なし |

- **A** は Rev 0.2 と同じパワー段の回路です。
- **B** の注意点 (24V 系):
  - CH32M030 の VS 絶対最大は 30V、VHV の動作範囲は 5〜28V です (データシート表 3-1)。
    24V 系は安定化電源専用とし、回生やサージで 28V を超えないようにしてください。
    主基板の VHV は R10 47Ω + D4 27V で保護しています。
  - TKR74F04PB はゲート電荷が大きいので、VDD8 LDO (35mA) の予算を確認してください。
    `8 × Qg × fPWM + MCU の消費 ≤ 35mA` が条件です (例: Qg 150nC なら fPWM ≤ 20kHz)。
    Qg はデータシートで確認してください。
  - TO-220SM(W) のランドは、KiCad 標準の TO-263-2 で暫定的に作っています。
    東芝提供のランドパターンに差し替えてから発注してください。
- **C** は SOT-23 の小型品です。小型 DC モータやステッピング (≤1.5A/相) 向けです。
- **D** は基板間コネクタの全信号を、TOP 面のピンヘッダへそのまま引き出します (シルクに信号名)。
  外付けのパワー段・既製ドライバ・評価用の負荷などをつなぎます。ゲート抵抗・プルダウン・シャント・分圧は外付け側で用意してください。

## 基板間コネクタのピン配置 (主基板 J9/J10 = 子基板 J1/J3, 同じ番号同士が嵌合)

子基板のソケットは 270° 回転させて BOTTOM 面に置いています。こうすると、裏返して重ねたときに**同じ番号のピン同士**が
嵌合します。`gen_pcb.py` の `mate_socket()` が全ピンの座標一致を検証します。

**J9 / J1 (電源 2x5)**: 奇数ピン = VBUS ×5、偶数ピン = GND ×5 (並列で約 10A)

**J10 / J3 (信号 2x11)**

| ピン | 信号 | ピン | 信号 |
|---|---|---|---|
| 1 | HO0 (ゲート H0) | 2 | SW0 (OUT0 / VS0) |
| 3 | LO0 | 4 | GND |
| 5 | HO1 | 6 | SW1 |
| 7 | LO1 | 8 | ISA_SEL (OPA3 +入力, JP7 で選択) |
| 9 | HO2 | 10 | SW2 |
| 11 | LO2 | 12 | GND |
| 13 | HO3 | 14 | SW3 |
| 15 | LO3 | 16 | ISB_SEL (OPA4 +入力, JP5 で選択) |
| 17 | ISH (シャント共通端, ケルビン) | 18 | GND |
| 19 | BEMF_U (分圧済み) | 20 | BEMF_V |
| 21 | BEMF_W | 22 | NTC (10kΩ B3435 → GND) |

HO/LO/SW は各レッグの順に並べてあり、QFN のゲートピン (主基板で左向き) から J10 まで交差せずに配線できます。
SWx は相出力とブートストラップの帰路 (VSx) を兼ねるため、子基板側ではハイサイド MOSFET のソースへ最短で接続しています。

## 基板レイアウト (2 層)

生成手順 (`hardware/gen_pcb.py`):

1. 部品を配置します。
2. Freerouting 1.9 で自動配線します。
3. 大電流ネットの周囲をベタで太らせます。
4. GND ベタ (両面) とスティッチングビアを入れます。
5. 自動配線で残った接続を格子 A* で補修します。DRC が増えない経路だけを採用します。
6. DRC を実行します。
図は `docs/pcb/*_top.svg` / `*_bottom.svg` です (BOTTOM 面は裏から見た鏡像)。

### 主基板 (60 × 42mm) — ご指定の配置

当初は 56mm 幅で配置しましたが、QFN (0.35mm ピッチ) 右側ピンの引き出しが 2 層で収まらなかったため、右側を 4mm 広げました。

| 領域 | 部品 |
|---|---|
| **右** | CH32M030 (QFN48, ゲートピンが左 = J10 側, USB ピンが右 = USB-C 側を向くよう 180° 回転), USB-C (右辺), GPIO J6 (右辺), UART J5 / SDI J7 (上辺), HALL J3 / I2C J4 (下辺), 水晶, RESET / USER・BOOT |
| **左上** | 電源: J1 (2x4 ピン) → F1 → Q9/U4 理想ダイオード → VBUS、USB-PD 経路 F3 → Q10/U5、TVS、78L05、VHV 保護、電源 LED |
| **左下** | 基板間コネクタ J9/J10 (BOTTOM 面, 子基板のパワー段が真下に来る)、センシング選択 JP2〜JP4・QII 選択 JP8 (TOP 面) |

### 子基板 (TOP 面から見た図。主基板とは左右が反転)

- 各レッグは縦一列に並びます (上から順に):
  - シャント
  - ローサイド (ソース上)
  - SW 行 (出力ピンヘッダ)
  - ハイサイド (ドレイン下)
  - VBUS 帯
- 大電流が流れる経路はすべて TOP 面のベタで太く取っています。ISH 帯・各レッグの SRC/SW・VBUS 帯から J1 への引き込みが該当します。
- BOTTOM 面は GND ベタです。バスシャント R70 は ISH 帯の端に置き、GND ベタへ落としています。
- ゲート抵抗・プルダウン・ゲート確認 LED は各レッグの左の列にあり、LED は外側 (TOP 面) から見えます。
